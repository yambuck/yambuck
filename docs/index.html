Yambuck

Simple Linux app installs. One guided installer for Linux software that works the same on every distro, instead of distro-specific app stores and package formats.

{% include hero-art.html %}

Open Terminal and run:

curl --proto '=https' --tlsv1.2 -sSf https://yambuck.com/install.sh | bash

Installs Yambuck for your account in ~/.local/bin. No password needed.

Manual Download

Yambuck is in alpha preview. Core flows work, with ongoing reliability improvements.

Need to remove Yambuck later? Uninstall instructions.
